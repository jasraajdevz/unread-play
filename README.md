# UNREAD

A short horror game that never stops being a messaging app.

Play it: https://jasraajdevz.github.io/unread-play/

Best on a phone. It runs on real elapsed time — close it and come back later and
it will have moved on without you. Settings → Reset this device starts again.

A work of fiction. Loop is a made-up messenger; every name and number in it is invented.
